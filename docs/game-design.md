## 1. 游戏概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **游戏名称** | Token Wars: 算力征途 |
| **类型** | 赛博朋克多人浏览器游戏 (Cyberpunk Multiplayer Browser Game) |
| **目标平台** | 浏览器（桌面优先）、Electron打包（Steam发行） |
| **技术栈** | Node.js + Express + Socket.IO / Phaser 3 |
| **游戏模式** | PvP竞技场、AI傀儡竞技场、合作采掘 |
| **美术风格** | 赛博朋克、霓虹灯、暗黑主题 |
| **目标受众** | 喜欢竞技游戏的PC玩家、区块链/赛博朋克文化爱好者 |

### 1.2 核心概念

在反乌托邦的近未来，算力（GPU计算能力）已成为比黄金更珍贵的资源。玩家扮演"算力猎人"——游走于数据废土的自由黑客，通过战斗、采掘和策略博弈来争夺名为"Token"的算力碎片。每一个Token都代表真实的计算权重，谁掌握了更多Token，谁就拥有了改写数字世界的力量。

### 1.3 游戏体验目标

- **紧张刺激的战斗**：快节奏的实时PvP，每场战斗都充满风险与回报
- **深度的战略层**：AI傀儡的Token配置和训练创造了独特的异步竞技体验
- **持续的成长感**：从采集第一个Token到登顶AELO排行榜，成长曲线清晰可见
- **社交竞技快感**：赛季排名、锦标赛、好友对战构建了丰富的社交竞争生态

### 1.4 世界观设定

公元2147年。全球算力网络"织网"（The Weave）覆盖了整个地球，所有计算资源都被量子化的Token所代表。巨型企业垄断了大部分算力，而散落在网络边缘的算力碎片成为自由猎人争夺的对象。你是一名刚刚接入织网的算力猎人，装备简陋但意志坚定。在这片数据废土中，你将通过战斗、交易和策略积累Token，最终成为算力战争的传奇。

### 1.5 项目状态

当前版本: **v0.3.0 (Demo)**

- Combat + Mining + AI Arena 基础功能已完成
- PvP匹配、背包、聊天系统开发中
- 计划 Steam 发行（通过 Electron 打包）

## 2. 设计支柱

### 2.1 Token is Power（算力即力量）

**一切围绕Token运转。** Token不仅是货币，更是力量的核心象征。你的战斗力、防御力、速度和经济效率都直接取决于所持有的Token数量和质量。Token的获取需要冒险，Token的使用需要策略，Token的损失意味着真正的代价。

**设计实现：**
- 每个Token有四个维度（攻击/防御/机动/经济），影响对应属性
- AI傀儡完全由Token配置驱动行为决策
- PvP死亡掉落10% Token，创造真实的紧张感
- Token的稀缺性通过稀有度系统和来源限制来维持

### 2.2 Risk vs Reward（风险与回报）

**每个行动都有有意义的权衡。** 玩家必须在安全采掘和冒险攻击之间做出选择。携带大量Token时，死亡损失更大；携带少量Token时，PVP收益更小。战斗、采掘和AI训练都需要玩家评估风险承受能力。

**设计实现：**
- 采掘安全但效率有限，PVP高风险但奖励丰厚
- 死亡掉落机制使高Token持有者成为"赏金目标"
- AI Arena 异步战斗不会丢失Token，但需要投入Token到傀儡配置中
- 赛季排名奖励与投入时间正相关

### 2.3 Social Competition（社交竞技）

**PvP和AI Arena创造多层竞争循环。** 实时PvP提供直接的对抗快感，AI Arena提供策略深度和异步竞争。排行榜、赛季和锦标赛连接两种模式，形成统一的竞争生态。

**设计实现：**
- 实时PvP：操作技巧的直接对抗
- AI Arena：策略配置的间接对抗，支持异步对战
- AELO排名系统贯穿两种模式
- 每周赛季和巅峰锦标赛创造定期竞争节点

### 2.4 Accessible Depth（易上手难精通）

**入门简单，深度无限。** 新手可以在5分钟内理解基本操作并开始采掘。但Token的最佳配置、AI行为树的权重调优、地图特性的利用提供了数百小时的学习曲线。

**设计实现：**
- WASD + 鼠标直观操作的即时战斗
- AI傀儡的Token盘配置从简单加减法到复杂的行为概率优化
- 8优先级决策树创造可分析可优化的行为空间
- 地图和赛季buff提供持续的meta变化

## 3. 核心循环

### 3.1 Moment-to-Moment（0-30秒）

玩家在即时层面执行的操作循环：

1. **移动** - WASD控制角色在房间内移动
2. **攻击** - J键近战攻击（25伤害，40范围，0.8s冷却）
3. **射击** - K键远程射击（15伤害，400范围，0.5s冷却）
4. **闪避** - 空格键冲刺（150px距离，3s冷却）
5. **采掘** - 在采掘节点附近保持位置进行自动采集
6. **使用物品** - E键使用背包中的道具

**战斗决策树：**
```
进入房间 → 索敌 → {
  有敌人: 评估实力 → { 有利: 近战+射击连击 | 不利: 冲刺逃跑 }
  无敌人: 寻找采掘节点 → { 找到: 开始采掘 | 未找到: 巡逻 }
}
→ 响应伤害 → { HP<30%: 使用药水或撤退 | HP>30%: 继续当前行动 }
```

### 3.2 Session Loop（5-30分钟）

单次游戏会话的循环：

1. **进入大厅** → 选择游戏模式
2. **PvP模式** → 排队匹配 → 进入战斗 → 死亡/胜利 → 收集Token → 返回大厅
3. **AI Arena模式** → 配置傀儡Token盘 → 进入异步匹配 → 观看战斗回放 → 训练傀儡 → 领取每日奖励
4. **采掘模式** → 进入采掘房间 → 寻找节点 → 采集Token → 防御其他玩家 → 撤离

### 3.3 Long-term Loop（数小时-数周）

长期成长循环：

```
采集Token → 积累财富 → {
  强化PvP角色（装备更好的Token）
  训练AI傀儡（投入Token到训练）
  提升AELO排名
}
→ 赛季结算 → 获得赛季奖励 → 新赛季开始 → 重复
```

**关键时间节点：**
- 每日：AI Arena每日奖励（24小时冷却）
- 每周：赛季重置和结算
- 每月：巅峰锦标赛（Top 16单淘汰赛）

## 4. 玩家角色

### 4.1 角色原型

赛博朋克风格的"算力猎人"——穿戴着改装义体和数据装甲的自由黑客。

### 4.2 基础属性

| 属性 | 基础值 | 说明 |
|------|--------|------|
| HP | 100 | 生命值，归零后死亡 |
| 移动速度 | 200 px/s | WASD移动速度 |
| 冲刺距离 | 150 px | 空格键瞬间位移距离 |
| 冲刺冷却 | 3s | 两次冲刺的最小间隔 |
| 近战伤害 | 25 | J键攻击伤害 |
| 近战范围 | 40 px | 近战攻击判定距离 |
| 近战冷却 | 0.8s | 两次近战的最小间隔 |
| 远程伤害 | 15 | K键射击伤害 |
| 远程范围 | 400 px | 射击判定距离 |
| 远程冷却 | 0.5s | 两次射击的最小间隔 |
| 弹道速度 | 600 px/s | 子弹飞行速度 |

### 4.3 能力键位

| 按键 | 能力 | 效果 |
|------|------|------|
| WASD | 移动 | 上下左右移动 |
| J | 近战攻击 | 40px范围，25伤害 |
| K | 远程射击 | 400px范围，15伤害，发射弹道子弹 |
| 空格 | 冲刺 | 150px瞬间位移，3s冷却 |
| E | 使用物品 | 使用当前装备的物品 |

### 4.4 死亡与重生

- HP降至0时死亡
- 死亡时掉落背包中10%的Token（向下取整，最少1个）
- 击杀者获得击杀者50%的掉落Token作为奖励
- 剩余50%的掉落Token销毁，从经济系统中移除
- 重生时间：3秒
- 重生后HP恢复至100
- 重生位置为房间安全区或随机安全位置

### 4.5 背包

- 最大容量：20格
- 每格可存放1个物品或1个Token
- Token不占用背包格（独立存储系统）

### 4.6 Token对属性的影响

玩家装备的Token直接影响战斗属性：

| Token类别 | 影响属性 | 效果公式 |
|-----------|----------|----------|
| Attack Token | 攻击伤害 | `伤害 = 基础伤害 × (1 + Σ(attack_multiplier × rarity_multiplier))` |
| Defense Token | HP上限 | `HP = 100 × (1 + Σ(defense_multiplier × rarity_multiplier))` |
| Mobility Token | 移速/冲刺 | `速度 = 200 × (1 + Σ(mobility_multiplier × rarity_multiplier))` |
| Economy Token | 采掘效率 | `采掘 = 基础速率 × (1 + Σ(economy_multiplier × rarity_multiplier))` |

## 5. Token经济系统

### 5.1 Token概述

Token是游戏的核心货币和力量来源。每个Token具有两个维度：
- **类别** (Category): 攻击/防御/机动/经济
- **稀有度** (Rarity): Common / Uncommon / Rare / Epic

### 5.2 类别影响

| 类别 | 图标色 | 主要影响 | 次要影响 |
|------|--------|----------|----------|
| Attack | 红色 (#ff006e) | 增加所有伤害输出 | 略微降低防御 |
| Defense | 蓝色 (#00d4ff) | 增加HP和抗性 | 略微降低速度 |
| Mobility | 绿色 (#00ff88) | 增加移动和冲刺速度 | 略微降低伤害 |
| Economy | 金色 (#ffaa00) | 增加采掘速率和奖励 | 略微降低HP |

### 5.3 稀有度倍数

| 稀有度 | 倍数 | 颜色 | 出现概率（采掘） | 出现概率（竞技场奖励） |
|--------|------|------|-----------------|----------------------|
| Common | 1.00x | 灰色 | 60% | 40% |
| Uncommon | 1.10x | 绿色 | 25% | 35% |
| Rare | 1.22x | 蓝色 | 12% | 20% |
| Epic | 1.35x | 紫色 | 3% | 5% |

### 5.4 Token来源

#### 采掘节点
- 随机生成在房间中
- 每2秒产出5个Token
- 节点持续60秒后枯竭
- 枯竭后15秒重新生成
- 最多同时存在5个活跃节点

#### PvP战斗
- 击杀掉落：被击杀者掉落10% Token
- 击杀者获得其中50%
- 剩余50%销毁

#### AI Arena奖励
- 每日奖励：登录领取随机稀有度的Token
- 竞技场排名奖励：赛季结束按AELO排名发放
- 锦标赛奖励：巅峰锦标赛参与者另有奖励

#### 赛季奖励
- 每周赛季结算，按最终排名发放Token
- 前100名获得额外稀有Token奖励

### 5.5 Token消耗

| 消耗途径 | 说明 |
|----------|------|
| AI傀儡训练 | 投入Token训练傀儡，消耗Token提升星级 |
| Token盘槽位 | 为AI傀儡安装Token，占用槽位 |
| 物品制作 | 使用Token合成战斗道具 |
| 死亡损失 | PvP中死亡掉落10% |

### 5.6 经济平衡目标

- 每日活跃玩家期望收益: 200-500 Token
- Token通胀率: 通过死亡销毁机制控制在5%以内
- Epic Token保有率: 不超过总Token池的8%
- 经济下沉: 通过AI训练消耗和死亡销毁维持Token价值

## 6. PvP战斗系统

### 6.1 概述

PvP战斗是实时多人对战系统，发生在程序生成的地下城房间中。玩家使用WASD移动、鼠标瞄准，通过J/K/空格/E四个按键进行战斗。

### 6.2 操作方式

**方案一：键盘+鼠标（推荐）**
- WASD：移动
- 鼠标：瞄准方向
- 左键：近战攻击
- 右键：远程射击
- 空格：冲刺
- E：使用物品

**方案二：纯键盘**
- WASD：移动
- 方向键或鼠标：瞄准
- J：近战攻击
- K：远程射击
- 空格：冲刺
- E：使用物品

### 6.3 匹配系统

- 基于AELO评分的匹配算法
- 匹配窗口：±200 AELO（初始），逐步放宽至±500
- 最大匹配等待：60秒，超时后放宽匹配条件
- 最低匹配玩家数：2人

### 6.4 战斗流程

1. **匹配** → 队列等待 → 匹配到对手
2. **加载** → 随机选择地图 → 进入房间
3. **倒计时** → 3-2-1 开始
4. **战斗** → 实时对战，无时间限制，直到一方死亡
5. **结算** → Token分配 → AELO更新 → 返回大厅

### 6.5 伤害计算

**近战伤害公式：**
```
实际伤害 = 25 × (1 + 攻击Token加成) × (1 - 目标防御减免)
```

**远程伤害公式：**
```
实际伤害 = 15 × (1 + 攻击Token加成) × (1 - 目标防御减免)
```

防御减免上限：60%（即最多减少60%所受伤害）

### 6.6 Token掉落机制

- 死亡玩家掉落背包Token总量的10%（向下取整，最少1个）
- 击杀者获得掉落Token的50%
- 剩余50%销毁（经济下沉）
- 示例：
  - 持有100 Token → 掉落10 → 击杀者获得5 → 5销毁
  - 持有5 Token → 掉落1 → 击杀者获得1（最少规则）→ 0销毁
  - 持有0 Token → 掉落0 → 无任何奖励

### 6.7 地图设计

PvP战斗发生在小型竞技场地图中（与AI Arena地图不同）：

| 地图 | 尺寸 | 特征 |
|------|------|------|
| 废弃机房 | 800×600 | 对称布局，多个障碍物 |
| 数据回廊 | 1200×400 | 长型地图，两端重生 |
| 核心枢纽 | 600×600 | 小型激烈地图，中央开放 |

### 6.8 弹道系统

- 射击发射可见弹道子弹
- 子弹速度：600 px/s
- 子弹碰撞半径：8px
- 子弹碰撞到墙壁后销毁
- 子弹碰撞到敌方玩家后造成伤害并销毁
- 最大同时存在子弹数：5发（超出后最旧子弹自动销毁）

## 7. AI傀儡竞技场

### 7.1 概述

AI傀儡竞技场是Token Wars的核心创新系统——一种异步PvP模式，玩家部署由Token驱动的AI傀儡进行自动战斗。这创造了一个"策略而非操作"的深度竞争层，让不同技能水平的玩家都能参与竞技。

**核心理念：** 你不是直接控制你的战斗单位。你通过选择和配置Token来决定他们的行为模式。Token的质量、数量和组合决定了你的AI傀儡在竞技场中的表现。

### 7.2 Token → 决策权重系统

这是AI傀儡竞技场的核心机制。每个装载到傀儡Token盘中的Token都会影响傀儡的行为决策概率。

**Token盘：** 每个AI傀儡有N个Token槽位（初始4个，可通过训练扩展）。

**权重映射：**
```
Token类别 → 影响的行为优先组：
  Attack Token   → 倾向 aggressive_pursue, seek_lowest_hp
  Defense Token  → 倾向 defensive_formation, flee_when_low_hp
  Mobility Token → 倾向 patrol_center, random_wander
  Economy Token  → 倾向 collect_nearest_token, patrol_center
```

**权重计算：**
```
某行为概率 = 该行为关联类别的Token力量之和 / 所有Token力量之和

Token力量 = Σ(Token的类别权重 × 稀有度倍数)
```

**示例：** 如果一个傀儡装备了3个Attack Token（2 Common + 1 Epic）和1个Defense Token（Uncommon），则：
- Attack力量 = (1.0 + 1.0 + 1.35) = 3.35
- Defense力量 = 1.10
- 总力量 = 3.35 + 1.10 = 4.45
- aggressive_pursue概率 ≈ 3.35 / 4.45 × (该行为占Attack组的比例)
- defensive_formation概率 ≈ 1.10 / 4.45 × (该行为占Defense组的比例)

### 7.3 8优先级决策树

每个AI傀儡在每一回合（2秒）根据以下决策树选择行动：

| 优先级 | 行为 | 触发条件 | 效果 |
|--------|------|----------|------|
| 1 | seek_lowest_hp | 有敌方HP<30% | 向HP最低的敌方单位移动并攻击 |
| 2 | seek_nearest_enemy | 有敌人在视野内 | 向最近的敌方单位移动并攻击 |
| 3 | flee_when_low_hp | 自身HP<25% | 向远离最近敌人的方向移动 |
| 4 | collect_nearest_token | 地图上有Token可拾取 | 移动到最近的Token并拾取 |
| 5 | patrol_center | 无明确威胁 | 向地图中心移动，巡逻模式 |
| 6 | defensive_formation | 友方单位在附近 | 靠近最近的友方单位，形成防线 |
| 7 | aggressive_pursue | 最近敌人在3格外 | 以1.3倍速度向最近敌人移动 |
| 8 | random_wander | 以上都不满足 | 在地图内随机移动 |

**决策解析逻辑：**
```
每回合（2秒）：
1. 评估当前状态（HP、位置、敌人位置、Token位置、友方位置）
2. 按优先级1-8依次检查触发条件
3. 如果触发条件满足 → 按Token权重概率决定是否执行该优先级
   - 如果该优先级的关联Token类别权重足够高 → 执行
   - 如果权重不足 → 降级到下一优先级，同时考虑该优先级的Token权重
4. 如果所有优先级都未触发或权重不足 → 执行random_wander
```

**详细行为说明：**

**seek_lowest_hp（优先级1）：** 猎杀残血目标。傀儡会无视距离，只要检测到敌方HP<30%就全力追击。此行为关联Attack Token。高Attack配置的傀儡会优先执行此行为。

**seek_nearest_enemy（优先级2）：** 常规接敌行为。傀儡向视野内最近的敌人移动，在攻击范围内时进行攻击。此行为关联Attack和Mobility Token。

**flee_when_low_hp（优先级3）：** 生存本能。当自身HP<25%时触发逃跑。傀儡会计算逃离最近威胁的最佳方向并全速移动。此行为关联Defense和Mobility Token。

**collect_nearest_token（优先级4）：** 资源采集。当地图上有可拾取的Token时触发。傀儡移动到Token位置并拾取，获得经济优势。此行为关联Economy Token。

**patrol_center（优先级5）：** 战略巡逻。傀儡向地图中心移动，在中心区域随机巡逻。适合控制型打法。关联Mobility和Economy Token。

**defensive_formation（优先级6）：** 团队防御。当有友方单位在3格以内时触发，选择与友方形成紧密阵型。关联Defense Token。

**aggressive_pursue（优先级7）：** 激进追击。当最近敌人在3格以外时，傀儡以1.3倍速度追击。关联Attack Token。

**random_wander（优先级8）：** 默认行为。完全随机移动，不可预测。关联Mobility Token。

### 7.4 异步战斗模拟

### 7.5 AELO评分系统

AELO（Arena Elo）是AI傀儡竞技场的排名系统，基于国际象棋的Elo评分算法修改而成。

**参数设置：**
- 初始评分：800
- K因子：20

**计算公式：**
```
预期胜率 = 1 / (1 + 10^((对手评分 - 自身评分) / 400))

新评分 = 旧评分 + K × (实际得分 - 预期胜率)

实际得分: 胜利=1, 平局=0.5, 失败=0
```

**排名段位：**

| 段位 | AELO范围 |
|------|----------|
| 青铜 | 0 - 999 |
| 白银 | 1000 - 1299 |
| 黄金 | 1300 - 1599 |
| 铂金 | 1600 - 1899 |
| 钻石 | 1900 - 2199 |
| 大师 | 2200+ |

## 8. 采掘系统

### 8.1 概述

采掘是Token的主要获取途径之一，也是相对低风险的Token积累方式。玩家在房间中寻找采掘节点并保持位置进行自动采集。

### 8.2 采掘节点

| 属性 | 值 | 说明 |
|------|-----|------|
| 最大数量 | 5 | 同时存在的节点上限 |
| 持续时间 | 60s | 节点被采掘到枯竭的时间 |
| 重生时间 | 15s | 节点枯竭后重新生成的时间 |
| 产出速率 | 5 Token/次 | 每次采掘获得的Token数量 |
| 采掘间隔 | 2s | 两次产出的时间间隔 |
| 基础效率 | 1× | 受Economy Token影响 |

### 8.3 采掘机制

- 玩家必须在采掘节点的有效范围内（默认80px）
- 玩家保持位置时自动开始采掘
- 采掘间隔2秒产出一批Token
- 移动或使用能力不会中断采掘（只要仍在范围内）
- 受到伤害不会中断采掘
- 玩家离开范围后停止采掘

### 8.4 经济Token对采掘的影响

```
有效采掘速率 = 1.0 × (1 + Σ(economy_multiplier × rarity_multiplier))
每次产出Token = 5 × 有效采掘速率（向下取整）
```

**示例：**
- 无Economy Token：每2秒产出5 Token，60秒总计150 Token
- 1 Epic Economy Token（1.35x）：每2秒产出6.75 ≈ 6 Token，60秒总计180 Token
- 3 Rare Economy Token（1.22×3）：每2秒产出18.3 ≈ 18 Token，60秒总计540 Token

### 8.5 风险因素

采掘时面临的风险：
- **PvP威胁：** 其他玩家可能攻击采掘中的你
- **位置暴露：** 采掘节点是地图上的固定点，容易被发现
- **采集价值：** 携带更多Token意味着死亡损失更大
- **撤离时机：** 何时停止采掘并撤离到安全区需要判断

### 8.6 节点生成规则

- 节点在空房间中随机位置生成
- 不与墙壁、其他节点或出生点重叠（最小距离60px）
- 节点生成时短暂发光动画（0.5s）
- 枯竭时节点变灰色并逐渐消失（1s动画）

### 12.4 通信协议

所有客户端-服务器通信通过 Socket.IO 事件实现。事件名称定义在 `shared/constants.js` 中。

**事件分类：**
- 连接事件（connect/disconnect）
- 房间事件（room:join/leave/update, player:joined/left）
- 战斗事件（player:move/attack/shoot/dash/died, state:sync, projectile:*）
- 采掘事件（mine:start/stop/reward, token:update）
- 背包事件（inventory:get/add/use/drop）
- 聊天事件（chat:message/broadcast）
- AI竞技场事件（ai_arena:*）
- PvP事件（pvp:*）

### 12.5 游戏状态管理

**服务器端:**
- 所有游戏逻辑在服务器端执行（权威服务器模型）
- 客户端发送操作指令，服务器计算并广播结果
- 状态同步频率：每秒20次 (50ms间隔)
- 房间状态包含：玩家列表、位置、HP、Token数量

**客户端:**
- 接收服务器状态更新进行渲染
- 客户端预测移动（减少延迟感）
- 定期与服务器状态校验
- 延迟补偿显示（ping显示）

### 12.6 AI Arena模拟架构

```
       │
       ▼

       │
       ├─ 加载双方Agent配置（Token盘）

       ├─ 更新AELO评分
       ├─ 分配Token经验奖励
       └─ 返回结果给双方客户端
```

## 14. 音效设计

### 14.1 音效分类

#### 战斗音效
| 音效 | 描述 | 优先级 |
|------|------|--------|
| 近战命中 | 电子撞击声，短促有力 | 高 |
| 激光射击 | 合成器pew声，尖锐 | 高 |
| 冲刺 | 空气呼啸声，带回声 | 中 |
| 受击 | 低沉电子脉冲+故障音 | 高 |
| 护盾吸收 | 能量场嗡鸣声 | 中 |
| 死亡 | 系统关闭音效+低频衰减 | 高 |

#### UI音效
| 音效 | 描述 | 优先级 |
|------|------|--------|
| 按钮点击 | 机械键盘click声 | 低 |
| 确认提示 | 清脆的beep上升音 | 低 |
| 错误提示 | 低沉的buzz下降音 | 低 |
| 菜单切换 | 轻微的电子swipe声 | 低 |
| 获得Token | 硬币般的叮当声（电子处理） | 中 |

#### 环境音效
| 音效 | 描述 | 优先级 |
|------|------|--------|
| 大厅环境 | 赛博朋克城市低鸣 | 中 |
| 战斗房间 | 服务器机房嗡嗡声 | 低 |
| AI Arena | 数据处理声（咔嗒脉冲） | 低 |

#### 音乐
| 音效 | 描述 | 优先级 |
|------|------|--------|
| 胜利 | 上升琶音合成器 | 中 |
| 失败 | 下降琶音合成器 | 中 |
| 主菜单 | 暗黑电子氛围音乐 | 低 |
| 激烈战斗 | 高速电子鼓+贝斯 | 低 |

### 14.2 技术实现

- 格式：OGG（Web）/ WAV（本地）
- 采样率：44.1kHz
- 位深度：16bit
- 空间音效：基于Phaser 3的空间音频API
- 音频管理：音效池化（Sound Pool）避免频繁创建销毁
- 音量控制：主音量/音效/音乐/环境 四个独立滑条
