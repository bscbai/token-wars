# token-wars 经济系统设计

## 经济循环设计

### Token 流通路径

1. **获取**：赛季奖励、任务奖励、市场购买
2. **消耗**：战斗、技能、升级、解锁内容
3. **销毁**：战斗消耗的 10% 永久销毁
4. **沉淀**：质押、长期持有奖励

### 通缩平衡

- 目标年通缩率：5-15%
- 通过赛季奖励补充流通量
- 动态调整销毁比例（5%-15% 区间浮动）

## 激励机制

| 行为 | 激励 | 目的 |
|------|------|------|
| 每日登录 | 50 token | 提升日活 |
| 赛季排名 | 奖池分成 | 竞争驱动 |
| 邀请好友 | 100 token/人 | 拉新 |
| 连续质押 | 年化 8-12% | 锁仓 |
