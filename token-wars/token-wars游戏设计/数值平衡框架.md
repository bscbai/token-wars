# token-wars 数值平衡框架

## 数值设计原则

1. **可控通缩**：token 总量持续减少，但不崩盘
2. **策略多样性**：没有绝对最优解，每种流派都有胜率
3. **新手友好**：初始 token 足以体验完整玩法
4. **长线可持续**：赛季重置后数值不膨胀

## 核心数值模型

### Token 经济循环

```
玩家持有 token
  ├→ 战斗消耗 → 销毁（10%）+ 奖池（5%）+ 对手（85%）
  ├→ 赛季奖励 → 从奖池分配
  ├→ 市场交易 → 自由流通
  └→ 质押收益 → 长期持有激励
```

### 平衡公式

- **攻击力** = base_atk × (1 + token_ratio × 0.3)
- **防御力** = base_def × (1 + holding_days × 0.05)
- **技能伤害** = skill_base × sqrt(token_cost / 100)

其中：
- `token_ratio` = 当前 token / 平均 token
- `holding_days` = 连续持有天数
- `token_cost` = 本次技能消耗量

## 平衡调整方法

1. **A/B 测试**：关键参数灰度发布
2. **数据监控**：每日跟踪胜率、token 流通速度、策略分布
3. **赛季调参**：每个赛季根据数据微调核心参数
4. **社区反馈**：定期收集玩家反馈，作为调参参考
