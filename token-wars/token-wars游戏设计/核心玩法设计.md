# token-wars 核心玩法设计

## 概述

token-wars 的核心玩法是一个基于 token 持有与消耗的实时策略对战系统。

## 核心机制

### 1. Token 持有与消耗
- 玩家通过持有 token 获得战斗资源
- 每回合消耗 token 进行攻击、防御或施放技能
- 消耗的 token 部分销毁（通缩机制），部分进入奖池

### 2. 策略选择
- **攻击流**：高消耗、高伤害，追求快速击溃对手
- **防御流**：低消耗、高生存，消耗对手资源
- **经济流**：积累 token，后期爆发

### 3. 胜负判定
- 对手生命值归零
- 对手 token 耗尽（无法行动）
- 回合结束时持有 token 更多（计时赛）

## 关键数值参数

| 参数 | 说明 | 参考值 |
|------|------|--------|
| 初始 token | 开局持有量 | 1000 |
| 每回合回复 | 自然恢复 | 50 |
| 攻击消耗 | 每次攻击 | 100-300 |
| 技能消耗 | 特殊技能 | 200-500 |
| 销毁比例 | 消耗中销毁占比 | 10% |
| 奖池比例 | 进入奖池占比 | 5% |
