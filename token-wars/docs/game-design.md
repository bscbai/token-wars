## 1. 核心概念

### 1.1 游戏愿景

在赛博朋克世界中，玩家控制"算力核心"，通过消耗、夺取、交易 Token（代表 GPU 算力）来壮大自己。Token 既是货币，也是弹药、护盾和经验值。

### 1.2 设计支柱

| 支柱 | 含义 | 设计检验 |
|------|------|---------|
| **易学难精** | 30 秒上手，30 小时仍有新发现 | 新手教程 < 8 分钟，协处理器组合提供持续深度 |
| **公平竞技** | 付费加速但不付费制胜 | 免费玩家能获得所有功能，付费只加速获取 |
| **策略大于操作** | 读对手比手速更重要 | 战斗三角 + 连招 = 决策博弈 |
| **每次登录都有目标** | 1 分钟到 1 小时都有事做 | 每日轮换 + 赛季进度 + 协处理器收集 |

### 1.3 核心循环

```
挂机挖矿(被动) → PvE 副本(主动) → PvP 竞技(对抗) → 商城消费(成长) → 背包管理(策略)
     ↑                                                                    ↓
     ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←
```

**循环钩子：**
- **即时 (0-5 分钟):** 挖矿产出 → 感受到资源增长
- **短期 (5-30 分钟):** 副本通关 → 获得协处理器碎片 → 收集进度推进
- **中期 (1-3 天):** 协处理器升级 → 解锁新技能 → 战斗力质变
- **长期 (1-4 周):** 赛季等级 → 限定奖励 → 排行榜位置

## 2. Token 系统

### 2.1 双 Token 经济

| Token 类型 | 来源 | 死亡掉落 | 用途 |
|-----------|------|---------|------|
| **稳定 Token** (白/绿/蓝/紫/橙) | 挖矿、副本、商城 | 是 (固定 30%) | 装备、升级 |
| **不稳定 Token** | 每日任务、副本、商城 | 否 | 技能弹药、护盾维护 |

**设计意图:** 免费玩家即使 PvP 失败也不会完全丧失战斗能力，因为弹药 Token 不会丢失。

### 2.2 基础弹药系统

每个玩家拥有独立的"基础弹药"池，解决新手"弹尽粮绝"问题。

| 属性 | 数值 | 说明 |
|------|------|------|
| 上限 | 50 发 | 不占背包空间 |
| 恢复速率 | 1 发 / 30 秒 | 脱战状态下自动恢复 |
| 伤害倍率 | 0.5x | 基础弹药攻击力为正常不稳定 Token 的 50% |
| 消耗优先级 | 最先消耗 | 优先消耗基础弹药，再消耗背包中的不稳定 Token |

**设计意图:**
- 新手永远能战斗，不会"弹尽粮绝"
- 但想打出高伤害，仍需收集高级不稳定 Token
- 挖矿产出的不稳定 Token 变成"增幅"而非"必需"

### 2.3 Token 稀有度

| 稀有度 | 颜色 | 掉率 | 攻击加成 | 防御加成 |
|--------|------|------|---------|---------|
| 普通 | 白 | 60% | +1 | +0 |
| 稀有 | 绿 | 25% | +3 | +1 |
| 史诗 | 蓝 | 10% | +7 | +3 |
| 传说 | 紫 | 4% | +15 | +8 |
| 神话 | 橙 | 1% | +30 | +15 |

### 2.4 死亡惩罚（修订版）

```
固定规则 (替代原 30-50% 随机):
  - 普通死亡: 掉落 30% 稳定 Token (向下取整)
  - 保底机制: 持有 ≤3 个稳定 Token 时不掉落
  - 新手保护: Lv5 以下死亡只掉落 15%

设计意图:
  - 可预测的损失 → 玩家能做风险管理
  - 保底 → 不会因连续死亡而绝望
  - 新手保护 → 前几级是安全的学习期
```

## 3. 协处理器系统

### 3.1 系统概述

协处理器是稀有 Token，提供独特技能。通过收集碎片升级，通过协同槽组合产生额外效果。协处理器是游戏的核心 retention 支柱。

### 3.2 协处理器分类

| 类别 | 现有 | 扩展 | 设计意图 |
|------|------|------|---------|
| **攻击型** | 闪电链 | + 穿透射击、分裂弹、灼烧印记 | 多样化伤害模式 |
| **防御型** | 护盾超载 | + 伤害转治疗、反弹屏障、紧急修复 | 坦克/辅助操作空间 |
| **机动型** | 区域隐身 | + 瞬移闪现、减速力场、传送门 | 空间博弈深度 |
| **经济型** | 算力磁铁 | + Token 翻倍、稀有率提升、离线加速 | Token 经济循环影响 |

**总数控制: 12-16 个。** 太少没收集深度，太多平衡噩梦。

### 3.3 协处理器详细列表

#### 攻击型

| 名称 | 效果 | 冷却 | Token 消耗 | 免费版 |
|------|------|------|-----------|--------|

| **分裂弹** | 攻击命中后分裂为 3 个弹片 | 10s | 2 | 分裂为 2 个 / 12s |
| **灼烧印记** | 命中叠加灼烧，3 层爆炸 | 1.5s | 1 | 2 层爆炸 / 2s |

#### 防御型

| 名称 | 效果 | 冷却 | Token 消耗 | 免费版 |
|------|------|------|-----------|--------|
| **护盾超载** | 吸收伤害并反射 30% | 12s | 2 | 吸收量减半 / 反射 15% |
| **伤害转治疗** | 3s 内受到伤害转为治疗 | 20s | 2 | 2s / 25s |
| **反弹屏障** | 创建反弹区域，弹回投射物 | 15s | 2 | 只反弹 50% / 20s |

|------|------|------|-----------|--------|
| **区域隐身** | 短暂隐身，下次攻击伤害 x2 | 15s | 2 | 1.5x / 20s |

| **减速力场** | 范围内敌人移速 -50% | 12s | 1 | -30% / 18s |
| **传送门** | 创建双向传送门，持续 10s | 30s | 2 | 持续 5s / 45s |

#### 经济型

| 名称 | 效果 | 冷却 | Token 消耗 | 免费版 |
|------|------|------|-----------|--------|
| **算力磁铁** | 拾取范围内所有掉落 Token | 20s | 1 | 范围减半 / 30s |
| **Token 翻倍** | 下次掉落 Token 数量翻倍 | 60s | 0 | 不翻倍，只 +50% |
| **稀有率提升** | 30s 内稀有掉落率 +20% | 120s | 1 | +10% / 180s |
| **离线加速** | 离线挖矿速率 +50% 持续 2h | 24h | 0 | +25% / 24h |

### 3.4 收集与升级

```
协处理器等级: ★ (基础) → ★★ (强化) → ★★★ (精通)

升级条件:
  ★ → ★★: 收集 3 个同类型碎片
  ★★ → ★★★: 收集 8 个同类型碎片

碎片来源 (概率表):
  - 单人副本 Boss: 15% 掉落随机碎片
  - 团队副本 Boss: 30% 掉落随机碎片
  - 世界 Boss: 按贡献度分配碎片
  - PvP 连胜宝箱 (3 连胜): 10% 掉落随机碎片
  - 每日任务: 奖励池中包含碎片
```

**数值缩放示例 (闪电链):**

| 等级 | 伤害 | 连锁目标 | 冷却 | Token 消耗 |
|------|------|---------|------|----------|
| ★ | 1.0x | 2 | 10s | 2 |
| ★★ | 1.3x | 3 | 8s | 2 |
| ★★★ | 1.5x | 4 | 6s | 1 |

### 3.5 协同效果系统

#### 协同槽机制

```
技能盘界面新增"协同槽" (位于 4x4 网格右侧)

协同槽规则:
  - 2 个协处理器放入同一协同槽 → 触发二阶协同
  - 3 个特定协处理器放入同一协同槽 → 触发三阶协同 (更强但更难凑齐)
  - 每个协同槽独立，最多 2 个协同槽 (Lv10 解锁第二个)

配方揭示流程:
  1. 获得第一个协处理器 → 协同槽 UI 亮起
  2. 悬停协同槽 → 显示 "需要: [攻击型] + [防御型]" (类别提示)
  3. 放入第一个 → 显示 "已放入: 闪电链 (攻击型)。等待: 防御型"
  4. 放入正确的第二个 → 协同激活动画 + 效果说明弹窗
  5. 激活后 → 图鉴永久记录
```

### 3.6 每日轮换增幅

```
每日 00:00 刷新:
  - 2 个协处理器获得"今日增幅" (+50% 效果数值)
  - 1 个协同效果获得"今日协同增幅" (效果触发概率翻倍)

目的:
  - 打破固定最优解
  - 每天登录都有理由试不同搭配
  - 创造 "今天适合打 XX" 的社交话题
```

### 3.7 平衡控制杆

```
平衡维度:
  1. ICD (Internal Cooldown) — 效果触发的最小间隔
  2. 触发概率 — 不是 100% 触发，而是概率触发
  3. 数值缩放 — 协同效果的数值随协处理器等级缩放
  4. 赛季轮换 — 每赛季禁用 2-3 个协同效果 (标记为"赛季休眠")
```

## 4. 战斗系统

### 4.1 战斗三角

4 个基础技能构成克制关系，每次交锋都有决策。

```
攻击(Q) 克制 → 护盾(E): 攻击穿透护盾，造成 50% 伤害
护盾(E) 克制 → 爆发(R): 护盾吸收爆发的全部 AOE 伤害
爆发(R) 克制 → 攻击(Q): 爆发打断攻击并击退
闪避(W) → 通用应对，但有 3s CD 不能滥用
```

**设计意图:**
- 4 个技能太少，无法靠"技能数量"撑深度
- 克制关系让每次交锋都有"猜拳"式决策
- 高手能通过读对手行为预判该用哪个技能

### 4.2 移动

- WASD 或点击移动，网格吸附
- 服务端校验，客户端做输入预测
- 200ms 延迟容忍

### 4.3 技能系统

| 快捷键 | 默认技能 | 消耗 | 冷却 | 类型 |
|--------|---------|------|------|------|
| Q | 基础攻击 | 1 Token | 0.5s | melee |
| W | 闪避翻滚 | 0 | 3s | movement |
| E | 算力护盾 | 1/s | 1s | shield |
| R | 算力爆发 (AOE) | 3 Token | 10s | aoe |

### 4.4 连招系统

在 2 秒内按特定顺序使用技能 → 触发连招加成。

| 连招 | 按键序列 | 效果 |
|------|---------|------|
| **蓄力爆发** | Q → Q → R | 最后一下 R 伤害 +30% |
| **反击连击** | E → Q → Q | 护盾期间攻击不消耗弹药 |
| **闪避反击** | W → Q | 闪避后 1s 内下次攻击暴击率 +50% |
| **爆破护盾** | R → E → Q | R 炸完后 E 吸收量翻倍 |
| **完美防御** | E → W → E | 第二次 E 持续时间 +100% |

**连招提示:** 技能图标边缘发光，提示"下一个技能可以连招"。

### 4.5 技能变体系统 (Token 驱动)

装备不同的 Token 组合会改变技能行为，而不仅仅是数值。

**基础攻击 (Q) 变体:**
- 装备 ≥3 个攻击型 Token → **穿刺攻击**: 攻击穿透直线上的所有目标
- 装备 ≥3 个防御型 Token → **重击**: 攻击附带 0.5s 眩晕
- 装备混合型 → **标准攻击**: 原版效果

**护盾 (E) 变体:**
- 装备 ≥3 个防御型 → **铁壁护盾**: 吸收量翻倍，但无法移动
- 装备 ≥3 个攻击型 → **反击护盾**: 受击时反弹 30% 伤害
- 装备混合型 → **灵活护盾**: 可移动但吸收量减半

**爆发 (R) 变体:**
- 装备 ≥3 个攻击型 → **毁灭爆发**: 伤害 +50%，范围 -50%
- 装备 ≥3 个防御型 → **守护爆发**: 不造成伤害，但为队友提供护盾
- 装备混合型 → **标准爆发**: 原版效果

**设计意图:** 收集不同稀有度的 Token 不只是"数值更强"，还能解锁不同技能变体。

### 4.6 技能盘

4x4 网格，Token 排列组合产生套装奖励:

| 排列 | 奖励 |
|------|------|
| 横排 4 个同类型 | +20% 攻击 |
| 竖排 4 个同类型 | +20% 防御 |
| 2x2 方块 | +10% 生命 |
| 对角线 | +15% 暴击率 |

**赛季轮换:** 每 4 周引入新的赛季图案奖励，打破最优解固化。

### 4.7 伤害公式

```
baseDamage = ATK * skillMultiplier * comboMultiplier
defense = DEF
rawDamage = max(baseDamage - defense, 1)
finalDamage = rawDamage * critMultiplier (暴击 1.5x, 基础 10% 概率)
```

### 4.8 防作弊

- 服务端校验冷却时间
- 服务端校验 Token 消耗
- 伤害公式服务端计算
- 移动频率服务端限制

### 4.9 PvP 中的读心博弈

```
对战节奏:
  1. 开局: 双方互相试探 (Q 试探攻击距离)
  2. 中盘: 开始读对手习惯
     - 对手爱用 Q → 我用 E 克制
     - 对手发现我用 E → 他切换 R 破盾
     - 我预判他的 R → 用 W 闪避
  3. 高潮: 连招窗口出现
     - 闪避成功 → 触发 "闪避反击" 连招窗口
     - 对手闪避 → 追击还是蓄力?
  4. 收尾: 弹药管理
     - 双方弹药都不多了 → 谁更节省谁赢
     - 基础弹药的 50% 攻击力 → 收尾阶段伤害下降
```

## 5. PvE 系统

### 5.1 副本类型

| 类型 | 人数 | 时长 | 奖励 |
|------|------|------|------|
| 单人副本 | 1 | 10-15 分钟 | 普通-稀有不稳定 Token + 协处理器碎片 |
| 团队副本 | 3-5 | 20-30 分钟 | 稀有-史诗稳定 Token + 协处理器碎片 |
| 世界 Boss | 全服 | 15 分钟 | 贡献度分配 (Token + 碎片 + 赛季经验) |

### 5.2 Boss 设计

**缓存控制器 (单人 Boss):**
- P1 (100-60%): 前方扇形攻击，红色预警 0.5 秒
- P2 (60-30%): "Token 吸收"技能，拉近玩家并持续消耗 Token
- P3 (30-0%): 狂暴，攻击加速，召唤小怪

**数据洪流 (团队 Boss):**
- P1: 全屏 AOE，需要团队分散站位
- P2: 数据链连接两名玩家，需要同步移动
- P3: 最终阶段，Boss 分裂为 3 个小 Boss，需要同时击杀

### 5.3 仇恨系统

```
threatTable: Map<playerId, threatValue>
伤害威胁 = damage * 1.0
治疗威胁 = healAmount * 0.5
Boss 攻击最高威胁目标
脱战范围: 距出生点 > 15 格
```

## 6. PvP 系统

### 6.1 竞技场模式

| 模式 | 人数 | 规则 | 时长 |
|------|------|------|------|
| 决斗 | 1v1 | 三局两胜 | ~3 分钟 |
| 团队竞技 | 3v3 | 单局淘汰 | ~5 分钟 |

### 6.2 匹配系统

- 评分系统: 初始 1000, +/-25 每场
- 队列按评分排序匹配
- 等待超过 2 分钟扩大匹配范围
- 新手保护: Lv5 以下优先匹配同等级玩家

### 6.3 反拖延机制

- 90 秒: 竞技场缩圈，边缘变为危险区域
- 120 秒: 中心生成"数据核心"，先击破者判胜
- 平局处理: 比较团队总伤害量

### 6.4 绝境反击 (3v3)

队友阵亡后，存活玩家获得增益:
- +20% 攻击 / -10% 防御 (玻璃大炮)
- 可叠加: 2 名队友阵亡 = +40% 攻击 / -20% 防御
- 持续 15 秒

### 6.5 连胜奖励防刷

- 每日最多 3 次连胜奖励
- 高连胜玩家优先匹配高连胜对手
- 跳过/挂机清零连胜
- 对手评分差不超过 300 才计数

### 6.6 赛季限定 PvP 模式 (每赛季轮换)

| 赛季 | 模式 | 规则 |
|------|------|------|
| 量子觉醒 | 量子分裂 | 死亡后分裂成 2 个小核心，3 秒后合并 |
| 暗影协议 | 猎杀名单 | 每人被分配一个暗杀目标 |
| 熵增危机 | 生存淘汰 | 毒圈缩小，最后存活者胜 |

## 12. 新手引导

### 12.1 "第一次同步" 教程

把教程包装成游戏叙事 — "你的算力核心刚被激活，需要完成第一次同步。"

| 阶段 | 时长 | 内容 | 教学目标 |
|------|------|------|---------|
| 核心激活 | 30s | UI 逐步亮起 + WASD 移动 | 移动操作 |
| 第一次采集 | 1min | 拾取 3 个不稳定 Token | Token 概念 |
| 第一次战斗 | 2min | 攻击训练假人 + 掉落装备 | 攻击 + 装备 |
| 技能解锁 | 2min | 闪避 + 护盾 + AOE 逐个解锁 | 全部 4 个技能 |
| 协同初体验 | 1min | 获得协处理器碎片 + 查看面板 | 协处理器系统 |

**预计时长:** 新手 5-8 分钟，有经验玩家 2 分钟内。

### 12.2 教程奖励

```
离开教程时玩家拥有:
  - 20+ 不稳定 Token (够打 1-2 场 PvP)
  - 2 个绿稳定 Token (装备后能感受到攻击力提升)
  - 1 个协处理器碎片 (知道 "我还缺 2 个")
  - 新手礼包 (一次性开包的爽感)

关键: 玩家离开教程时应该觉得自己 "已经变强了"
```

### 12.3 教程后引导

```
教程结束后弹出三条路径:
  - "去挖矿" → 绿色安全图标 (最安全的玩法)
  - "打副本" → 黄色中等图标 (PvE 体验)
  - "进入竞技场" → 红色危险图标 (PvP，不推荐新手但不阻止)

默认推荐: 挖矿 → 副本 → 竞技场
```

### 12.4 新手保护期 (Lv1-5)

```
保护规则:
  - PvP 死亡不掉落稳定 Token
  - 基础弹药上限 +50% (75 发)
  - 副本掉落率 +20%
  - 匹配时优先匹配同等级玩家
  - 大厅有 "新手" 标记

Lv6 时弹出:
  "你的算力核心已完成校准。新手保护期结束。现在，真正的战斗开始了。"
```

## 13. 经济平衡措施

### 13.1 通缩控制

- 攻击消耗 Token (弹药燃烧)
- 死亡掉落稳定 Token (固定 30%)
- 挖矿升级消耗 Token
- 协处理器升级消耗碎片

### 13.2 通胀控制

- 基础弹药有上限 (50 发)
- 挖矿有存储上限
- 积分获取有每日/每周上限
- 赛季限定物品数量有限

### 13.3 反霸服 (世界 Boss)

- 等级加权贡献: 低等级玩家获得贡献加成
- 随机事件: 数据缓存拾取，点名机制处理
- 技巧成分对抗纯数值碾压

### 13.4 免费玩家保护

- 功能性技能免费可得 (数值较弱)
- 不稳定 Token 永不掉落
- 每日/每周任务稳定产出
- 基础弹药永远可用
- 赛季重置不重置等级

### 13.5 经济流量校验

| 场景 | 流入/分钟 | 流出/分钟 | 净值 | 评估 |
|------|----------|----------|------|------|
| 新手挂机挖矿 | +1 基础弹药 + 1 挖矿 | 0 | +2 | ✅ 永远正收益 |
| 新手 PvE | +1 基础弹药 + 副本掉落 | -12 (基础弹药攻击) | 略负 | ⚠️ 需要副本掉落补偿 |
| 老手 PvP | +挖矿+弹药 | -24 (全速攻击) | 负 | ✅ PvP 应该是净消耗 |
| 老手 PvE | +挖矿+高级弹药 | -24 + 副本掉落 | 正 | ✅ PvE 应该是净产出 |

**关键原则: PvE 净产出，PvP 净消耗，挖矿保底。**
