## 2. Steam 发布清单

### 2.1 注册 Steamworks
1. 访问 https://partner.steamgames.com
2. 签署数字文书（需要个人 / 公司身份信息）
3. 支付 **$100** Steam Direct 费
4. 填写银行和税务信息（W-8BEN 非美国开发者用）

### 2.2 创建商店页面
需要的素材（详见第 4 节）：
- 主视觉图 (2560×1440)
- 至少 5 张截图
- 预告片 (30-120 秒)
- 短描述 + 长描述
- 系统需求
- 标签和分类

### 2.3 技术集成
- 集成 Steamworks SDK
  - 成就系统（建议 15-30 个成就）
  - 云存档
  - 好友邀请
- 商店页面提前 **2 周** 公示（积累愿望单）

### 2.4 审核与发布
- 审核周期：1-5 天
- 付费后 **30 天** 等待期
- 发布后可持续更新

### 2.5 收入分成
| 总收入 | 开发者 | Valve |
|--------|--------|-------|
| 0 - $1000万 | 70% | 30% |
| $1000万 - $5000万 | 75% | 25% |
| > $5000万 | 80% | 20% |

## 3. Epic Games Store 发布清单

### 3.1 注册开发者门户
1. 访问 https://dev.epicgames.com
2. 创建组织（需要商业信息）
3. 人工审核 **3-5 个工作日**
4. 配置税务和支付信息

### 3.2 技术集成
- 集成 Epic Online Services (EOS)
  - 账号认证
  - 成就系统
  - 云存档
- 使用 BuildPatch Tool 上传构建

### 3.3 提交审核
- 审核周期：**2-4 周**
- 审核严格，建议提前 **2-3 个月** 提交
- 需要年龄评级（IARC 免费）

### 3.4 收入分成
| 引擎 | 开发者 | Epic |
|------|--------|------|
| 任意引擎 | 88% | 12% |
| 虚幻引擎 | 93% | 7%（5% 引擎版税免除） |

## 4. 素材要求

### 4.1 截图（Steam + Epic 通用）
| 要求 | Steam | Epic |
|------|-------|------|
| 最少数量 | 5 张 | 5 张 |
| 分辨率 | 1920×1080 | 1920×1080+ |
| 格式 | PNG/JPEG | PNG/JPEG |
| 内容 | 实际游戏画面 | 实际游戏画面 |

### 4.2 视觉素材
| 素材 | 尺寸 | 用途 |
|------|------|------|
| 主视觉图 | 2560×1440 | Steam 库 + 首页推荐 |
| 竖版视觉图 | 1200×1600 | Epic 商店 |
| 宽版 Logo | 1920×1080 | Steam 页面顶部 |
| Logo | 512×512 透明 PNG | 通用 |
| 缩略图 | 460×215 | Steam 搜索结果 |

### 4.3 预告片
- 时长：30-120 秒
- 内容：**实际游戏画面**（非纯预渲染动画）
- 关键：前 5 秒抓住注意力
- 帧率：60fps 推荐

### 4.4 文案
| 类型 | Steam | Epic |
|------|-------|------|
| 短描述 | 可选 | 160-300 字符 |
| 长描述 | 推荐 | 2000-4000 字符 |
| 关键特性 | 3-5 个 | 5-10 个 |

## 5. 技术准备

### 5.1 Electron 桌面版 —— ✅ 已完成

```
npm run build       # 构建 Windows 版
npm run build:mac   # 构建 macOS 版
npm run build:linux # 构建 Linux 版
npm run build:all   # 全平台构建
```

输出目录：`dist/Token Wars-{platform}-{arch}/`

### 5.2 Steamworks SDK 集成
需要完成（未开始）：
1. 下载 Steamworks SDK (https://partner.steamgames.com)
2. 集成 `steam_api64.dll` 到 Electron 打包
3. 实现 Greenworks (Node.js Steamworks wrapper)
4. 对接成就、云存档、好友系统

### 5.3 Epic Online Services 集成
需要完成（未开始）：
1. 从 dev.epicgames.com 获取 SDK
2. 集成 EOS 账号认证
3. 实现成就和云存档

### 5.4 服务器部署
Token Wars 是多人在线游戏，需要：
- 生产服务器部署（可考虑：阿里云、腾讯云、AWS）
- 数据库（SQLite → 生产环境的迁移计划）
- DDoS 防护
- 监控和日志
