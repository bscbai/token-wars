# 协处理器剩余效果（防御/机动/经济） — 提案

## 背景

M6 垂直切片已落地攻击型 4 效果（闪电链/穿透射击/分裂弹/灼烧印记）与协处理器槽架构。
GDD §3.3 列出 16 个协处理器，剩余 12 个分属防御/机动/经济三类，尚未接入执行链路。

## 目标

- 补齐 12 个效果的服务端执行，复用 M6 的 `CoprocessorSystem.activate` 流水与 `EFFECT_HANDLERS` 分发。
- 每个效果接入对应子系统的正确接缝：伤害入口、移动、掉落、挖矿。
- 全部效果可测（单元测试覆盖核心语义），全量测试不回退。

## 非目标

- 不实现地面掉落系统（当前 loot 直送玩家）；`token_magnet` 以"范围环境 Token 收集"语义落地，待地面掉落上线后再切到拾取半径。
- 不实现协同槽（M7）。
- 不改动客户端渲染（仅服务端状态 + 已有事件）。
